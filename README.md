#  Amazon Sales, Transaction & Customer Dashboard using Power BI

##  Project Overview
This project is a **comprehensive multi-page Power BI dashboard** designed to analyze and visualize **Sales Performance, Transaction Behavior, and Customer Insights**.

The dashboard transforms raw data into **actionable business insights** using interactive visualizations, KPIs, and advanced data modeling techniques.

##  Dashboard Breakdown

### 🔸 1. Sales & Profit Analysis
- Total Sales, Profit, Discount, Tax, Net Amount KPIs
- Sales & Profit by Region and Month
- Currency-wise cost and pricing analysis
- Interactive filters: Country, Currency, Payment Method, Status

 **Insight:** Oceania region shows highest sales performance while Europe shows lower trends.

---

### 🔸 2. Transaction Insights
- Total Transactions: **60K+**
- Account Type Analysis (Credit, Current, Savings)
- Payment Method Analysis (Bank Transfer, Credit Card, Debit Card, PayPal)
- Monthly transaction trend analysis
- Country-wise transaction distribution

 **Insight:** Credit accounts dominate transactions and active transactions significantly exceed inactive ones.

---

### 🔸 3. Customer Analysis
- Customer segmentation (SME, Retail, Corporate)
- Risk profile distribution (High, Medium, Low)
- Regional customer activity (Active vs Inactive)
- Customer-level transaction details

 **Insight:** SME customers represent the largest segment, and customer risk is evenly distributed.
